# CivicLens AI — Architectural Blueprint

CivicLens AI is a modern full-stack civic intelligence platform that empowers citizens to report civic infrastructure issues (potholes, garbage, broken streetlights, water leakage, open drains) and provides municipal authorities with an AI-assisted operations desk to triage, dispatch, resolve, and verify complaints.

## 1. High-Level Design Principles

1. **Human-in-the-Loop AI Transparency:**
   The AI engine is an advisory copilot, not an infallible authority. Every recommendation generated by AI (category classification, severity level, department routing, duplicate candidates) is flagged with confidence scores and operating mode (`AI_GEMINI` vs. `RULE_BASED`). Municipal officers have explicit authority to review, confirm, or override AI recommendations with mandatory justification logs.

2. **Strict Complaint State Machine:**
   Complaint status transitions follow an enforced directed acyclic graph (DAG):
   `SUBMITTED` → `VERIFIED` → `ASSIGNED` → `IN_PROGRESS` → `RESOLVED` → `CITIZEN_VERIFIED`
   Any invalid leap (such as jumping directly from `SUBMITTED` to `RESOLVED`) is rejected by backend business validators with an HTTP 400 Bad Request.

3. **Privacy-Preserving Public Transparency:**
   The public transparency map and open ledger display sanitized complaint records where private citizen identity, email, and phone numbers are redacted. Public coordinates can be viewed by all citizens, while detailed personal information is restricted to assigned municipal officers and administrators.

4. **Resilient Multimodal Ingestion:**
   Citizens can capture evidence using device cameras, upload photos, dictate voice descriptions (Web Speech API in English and Hindi), and select precise map coordinates via GPS geolocation or interactive pin placement.

## 2. Core Subsystems

### A. Citizen Intake & Reporting Wizard
- **5-Step Accessible Stepper:**
  1. *Category & Media:* Image upload with preview, camera capture, file type verification.
  2. *Issue Details:* Title, description, and voice-to-text dictation.
  3. *Location Selection:* Geolocation auto-detect, reverse geocoding fallback, interactive Leaflet marker.
  4. *AI Analysis Review:* Live server-side classification, severity gauge, duplicate warning check, and user override.
  5. *Review & Confirmation:* Public visibility toggle, reference number generation (e.g. `CLN-2026-1025`).

### B. Multimodal AI Analysis & Routing Pipeline
- **Orchestrator (`app/services/ai_service.py`):**
  - **Gemini Vision Mode:** Sends image bytes and citizen prompt to Google Gemini multimodal model to detect infrastructure defects, evaluate public safety hazards, and compute severity.
  - **Deterministic Rule-Based Fallback:** If `GEMINI_API_KEY` is not configured, the service switches to a weighted keyword matching engine (`analysis_mode="RULE_BASED"`). The system remains 100% operational without external vendor dependency.
  - **Spatial Deduplication:** Evaluates existing unresolved complaints within radial proximity (default 150m) and temporal window (default 14 days) using the Haversine distance formula and title text similarity.

### C. Municipal Operations Desk
- **Queue Management:** Multi-attribute filtering by status, category, severity, department, ward, and overdue SLA status.
- **Triage & Assignment:** Re-route to correct department, assign to specific field officer with internal instructions.
- **Human AI Override:** Adjust category or severity with audit-logged justification reason.
- **Duplicate Review:** Mark candidate complaints as `CONFIRMED_DUPLICATE` (merging notifications) or `DISMISSED`.
- **Resolution Verification:** Officers must upload after-repair photographic proof before marking an issue `RESOLVED`.
- **Citizen Close-out:** Citizens receive real-time notifications to inspect the fix on site, confirm resolution (`CITIZEN_VERIFIED`), or reopen with mandatory feedback and 1-5 star ratings.

### D. Central Administration & Governance
- **Role-Based Access Control (RBAC):** `CITIZEN`, `OFFICER`, `ADMIN` with last active administrator demotion protection.
- **Department & SLA Tuning:** Configure departments, target resolution turnaround hours (e.g. PWD 48h, Sanitation 24h), contact emails, and coverage wards.
- **System Settings:** Runtime control over duplicate clustering radius, verification timeout days, and SLA targets.
- **Immutable Audit Trail:** Append-only logging of user status modifications, role promotions, status overrides, and settings changes with IP address and JSON diffs.

## 3. Real-Time Communication

The platform includes a WebSocket broadcast hub (`/ws/notifications`) with client reconnection logic. When a complaint status transitions or an officer is assigned a high-priority ticket, the backend triggers an instant notification event to connected clients. If WebSockets are unavailable or firewalled, the frontend seamlessly polls `/api/v1/notifications/unread-count` every 30 seconds.
